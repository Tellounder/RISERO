# Créditos y alcance de uso

## Identidad y contenido

La marca Rise Difusión, su logotipo, fotografías, piezas gráficas, nombres de artistas y contenidos musicales pertenecen a Rise Difusión y a sus respectivos autores.

## Repositorio público

El código se publica como caso de estudio para demostrar decisiones de diseño y desarrollo. La visibilidad pública del repositorio no concede permiso para reutilizar la marca, las imágenes, las obras musicales ni la identidad del cliente.

Las bibliotecas y dependencias de terceros conservan sus propias licencias. Para adaptar el desarrollo a otra identidad comercial se requiere reemplazar todos los activos, contenidos y configuraciones vinculados a Rise Difusión.
